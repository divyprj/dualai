# /gpt — ChatGPT Coordination & Obedience Skill

When the user invokes `/gpt` or asks for ChatGPT consultation/generation, the agent must strictly execute through the **Dual-AI Bridge**.

---

## 🎯 Mandatory Operating Principles

1. **100% COMPLETE & VERBATIM OUTPUT + BRIEF ANTIGRAVITY SUMMARY**:
   * Whenever ChatGPT generates a response via `/gpt`, the agent **MUST ALWAYS deliver the 100% complete, exact, uncompressed, full-fidelity verbatim text** generated by ChatGPT.
   * **NEVER summarize, truncate, abbreviate, or cut short the ChatGPT response** itself.
   * **Immediately after the verbatim response**, Antigravity must provide a **short, concise brief summary** summarizing the actionable decisions and next steps.

2. **Strict AI Role Division**:
   * **ChatGPT**: Sole authority for deep research, strategic reasoning, factual discography/catalogs, visual art prompts, and image generation (via DALL-E 3).
   * **Antigravity (Gemini)**: Responsible for code execution, file management, builds, transcoding, and device verification.
   * **Absolute Obedience**: If ChatGPT provides code, design specifications, or structural plans, the agent must completely follow and implement ChatGPT's exact directions.

3. **Single-Thread Continuity (CRITICAL & STRICT)**:
   * For any given project, always use the **exact same persistent ChatGPT conversation thread**.
   * **NEVER open new/blank chats** for an ongoing project. New conversations are ONLY permitted when explicitly instructed by the user or when completely switching to a new project.
   * **Target Thread for Raptile Studio**: The dedicated conversation thread titled `Instagram Automation F...` (under `gemini-gpt-bridge`).
   * When navigating in Playwright, always navigate directly to this persistent thread URL.

4. **Zero-Pollution Attachment Policy**:
   * **NEVER attach or send images/files with prompts** unless the user or prompt specifically requests image generation or visual analysis based on that file.
   * Pure architectural, coding, strategy, and conversational prompts must be sent as pure text with **zero attachments**.
   * Any attachment definition (`attachments.json`) must be auto-deleted immediately after upload so it never lingers to pollute subsequent prompts.

5. **Strict Zero-Modification on Generated Images**:
   * **NEVER crop, slice, trim, or downsample generated images**.
   * The user requires the **100% exact, original raw image file generated by ChatGPT**, bit-for-bit without any alterations, cropping, or manual editing.

5. **Strict Folder Separation**:
   * Bridge automation, browser profiles, and bridge logs live exclusively in `C:\Dev\gemini-gpt-bridge\`.
   * Project source code and assets live in the respective project folder.

6. **Raw Image Extraction Pipeline**:
   * Download the raw binary bytes generated by ChatGPT / DALL-E directly from the conversation.
   * Save the original full-resolution asset untouched into the project directory.
