---

## 🎯 Mandatory Operating Principles

1. **100% COMPLETE & VERBATIM OUTPUT (ZERO TRUNCATION / NO SUMMARIES)**:
   * Whenever ChatGPT generates a response via `/gpt`, the agent **MUST ALWAYS deliver the 100% complete, exact, uncompressed, full-fidelity verbatim text** generated by ChatGPT.
   * **NEVER summarize, truncate, abbreviate, or cut short the ChatGPT response** unless the user explicitly requests a summary.
   * Every diagram, code snippet, section, bullet point, and markdown block from `bridge/report.md` must be presented in full.

2. **Strict AI Role Division**:
   * **ChatGPT**: Sole authority for deep research, strategic reasoning, factual discography/catalogs, visual art prompts, and image generation.
   * **Antigravity (Gemini)**: Responsible for code execution, file management, builds, and device verification.
   * **Absolute Obedience**: If ChatGPT provides code, design specifications, or structural plans, the agent must completely follow and implement ChatGPT's exact directions.

3. **Single-Thread Continuity**:
   * For any given project, always use the **exact same persistent ChatGPT conversation thread**.
   * Never open new/blank chats for an ongoing project.
   * Target URL: `https://chatgpt.com/c/6a8ff4bb-926c-83ee-8515-22f7f6e40857`.

4. **Strict Folder Separation**:
   * Bridge automation, browser profiles, and bridge logs live exclusively in `C:\Dev\dual-ai\`.
   * Project source code and assets live in the respective project folder.

   * Write the task prompt clearly into `C:\Dev\dual-ai\bridge\prompt.md`.

4. **Execute & Obey**:
   * Implement ChatGPT's exact recommendations in the codebase.
