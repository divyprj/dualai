# 📜 DUAL-AI BRIDGE: CORE OPERATING RULES

### Rule 1: 100% Verbatim Fidelity (Non-Negotiable)
Any response received from ChatGPT through the Dual-AI Bridge must be presented in its 100% complete, uncompressed, unsummarized, verbatim form. Truncating, paraphrasing, or shortening the text is strictly forbidden.

### Rule 2: Division of Labor
- **ChatGPT**: High-order planning, deep reasoning, mathematical proofs, domain research, visual art synthesis.
- **Antigravity (Gemini)**: File I/O, compilation, automated tests, local execution, hardware monitoring.

### Rule 3: Single Persistent Thread
Never start new ChatGPT threads for an active project. Single-thread memory preserves context across sessions.

### Rule 4: File Isolation
The bridge engine lives strictly in `c:\Dev\dual-ai\`. No model binaries or extraneous files are stored here.
